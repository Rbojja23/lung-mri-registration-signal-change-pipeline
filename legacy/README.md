# Legacy Scripts

These scripts are the original CT-only lungmask pipeline. They are retained for
history and comparison only.

The supported v1.0 pipeline uses the modality-neutral loaders, TotalSegmentator,
segmentation QC, bounding-box/crop modules, bbox QC, and OsiriX export modules in
`src/`.

The legacy scripts may require `lungmask`, which is no longer an active
dependency of the supported pipeline.
